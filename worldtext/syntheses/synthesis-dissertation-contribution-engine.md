## What This Document Is

This synthesis applies the **OPERATION DESCRIBE** schema to the structural definition of [[entity-watson-hartsoe]]'s dissertation. In generative media systems, description no longer merely represents worlds; it operates systems that generate, revise, and stabilize them. By applying this logic of **operative description** recursively to the dissertation itself, this page maps the field, limits, methods, artifacts, and doors that constitute the dissertation's contribution engine.

## 1. Contribution Statement

### One-Sentence Version (The Suspicion)
This project investigates whether the concept of **operative description**—studied through the method of **thick prompting**—can isolate a distinct class of descriptive acts that govern the generation, revision, and traversal of moving-image **worldtexts** (recursive, state-bound simulation loops) instrumented via **c2.html**.

### Paragraph Version
Entering the fields of digital media, HCI, media studies, AI ethics, narrative theory, and practice-based research, this dissertation tests a specific suspicion: *Under what conditions does a description cease to be decorative and become operative?* Rather than treating prompting as a private trick or assuming that language is a deterministic compiler, this project establishes a testable framework around Gregory Bateson's "difference that makes a difference" formulation. We trace the generation-space delta ($\Delta G$) across prompt-output-revision loops to verify whether changes in description produce traceable changes in system states, visual style, or motion logic. By mapping these dynamics in moving-image settings (**ABC Cineosis**), we study the temporal failure modes and return loops that pressure the boundaries of generative worldmaking.

### The Strong Claim (Under Pressure)
> **A description becomes operative only when a difference in description produces a difference in the system’s next state ($\Delta G \neq 0$).**

## 3. Contribution Boundary & Uncertainty Protocol

We establish four distinct statuses to classify every claim made in the dissertation, maintaining a bounded and testable stance:

*   **DEFINED**: Terms stipulated and structured by the dissertation.
    *   *Operative Description*: A description that alters a system's action-space.
    *   *Thick Prompting*: A repeatable method of context engineering.
*   **TESTED**: Claims demonstrated and logged in at least one bounded loop.
    *   *Tool Schemas*: Verified that varying tool description parameters routes API execution.
    *   *Prompt Invariants*: Verified that setting hard material constraints alters LLM vocabulary selection.
*   **INTERPRETED**: Arguments supported by textual and media archives but contestable.
    *   *Worldtext*: The recursive hanging-together of prompts, outputs, revisions, interfaces, and interpretations.
    *   *ABC Cineosis*: The moving-image subcase testing whether duration/movement changes the loop.
*   **SPECULATIVE**: Suggestive claims that should not carry the core thesis.
    *   *"Language becomes code/executable"*: Rejected in favor of the narrower claim of natural language acting as a *routing layer* within application-defined schemas.

### What This Contribution IS
- A testable theory of operative description
- A method of thick prompting (see [[thick-prompt]])
- A vocabulary for worldtext (see [[concept-worldtext]])
- A practice-based study of generative media loops
- A way to analyze prompt-output-revision traces
- A bridge between media theory, HCI, and system interfaces
- A framework for steering generated worlds under probabilistic drift

### What This Contribution IS NOT
- A claim to have invented prompting or AI storytelling
- A general history of all generative AI
- A technical benchmark of model performance
- A universal theory of creativity or intentionality
- A pure art portfolio or vibes-only archive
- An "everything bagel" dissertation about AI and culture

### What Must Be True for the Contribution to Count
- **Operative description** is clearly defined and falsifiable (i.e. we document cases where $\Delta G = 0$).
- **Worldtext** is distinguishable from storyworld, interface, and prompt history.
- **Thick prompting** is described as a repeatable research method.
- The case studies demonstrate the theory through recorded deltas.
- The prototype work (e.g. `c2.html`) supports the argument by instrumentation.
- The committee (led by [[entity-jay-bolter]]) can identify the boundary constraints of the contribution.

## 6. Validation & Delta-G Scale

To verify whether a description operates, we measure its **generation-space delta ($\Delta G$)** where:

$$\Delta G = G_{\text{description}} - G_{\text{default}}$$

We evaluate the efficacy of the framework across five levels of delta:

| Level | Delta Class | Observable Mechanism | Failure Criteria |
| :--- | :--- | :--- | :--- |
| 1 | **No $\Delta G$ (Decorative)** | Changing the description yields no change in outputs or system routing. | The term is redundant and should be cut. |
| 2 | **Weak $\Delta G$ (Interpretive)** | Changes the viewer's interpretation but doesn't change model execution or revision path. | The description does not operate the system. |
| 3 | **Medium $\Delta G$ (Generative)** | Changes generated content, visual style, or motion logic. | The change is chaotic and non-reproducible. |
| 4 | **Strong $\Delta G$ (Structural)** | Changes the revision path, constraint limits, or world-state continuity across loops. | The loop collapses into default platform priors. |
| 5 | **Full $\Delta G$ (Systemic)** | Changes the entire loop: prompt, computational mediation, moving-image output, and the return path that shapes the next prompt. | The loop breaks down into a linear pipeline. |

### Field/Literature Neighbors and Contradictions
- **Operative Description**: Neighbors include *ekphrasis*, *prompting*, *speech acts*, *procedural rhetoric*. Opposes *description as passive representation*.
- **Worldtext**: Neighbors include *imagetext*, *storyworld*, *database narratives*, *interface ecologies*. Opposes *outputs as isolated artifacts*.
- **Thick Prompting**: Neighbors include *thick description*, *Research through Design (RtD)*, *autoethnography*, *annotated portfolios*. Opposes *prompting as a private trick or productivity hack*.
